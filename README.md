# Serial Driver

Сервис отправляет команды подключённому USB-последовательному устройству и читает ответы. При отключении ищет порт и подключается снова. Ручка `POST /api/serial/command` на порту `8000` принимает JSON `{"data":"команда"}` и возвращает ответ микроконтроллера в поле `data`.

```bash
make gen
go run ./cmd/service
```

Описание API: [Swagger UI](http://localhost:8000/swagger/index.html).

Скорость порта задаётся переменной `BAUD_RATE` (по умолчанию `9600`). Адрес HTTP-сервера задаётся `PORT`, путь к спецификации — `OPENAPI_SPEC`, уровень логирования — `LOG_LEVEL`.
