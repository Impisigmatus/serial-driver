# Serial Driver

Сервис читает строки из подключённого USB-последовательного устройства. При отключении ищет порт и подключается снова. Последнее полученное сообщение доступно через `GET /api/serial/latest` на порту `8000`; пока сообщение не получено, ручка возвращает HTTP 503.

```bash
make gen
go run ./cmd/service
```

Описание API: [Swagger UI](http://localhost:8000/swagger/index.html).

Скорость порта задаётся переменной `BAUD_RATE` (по умолчанию `9600`). Адрес HTTP-сервера задаётся `PORT`, путь к спецификации — `OPENAPI_SPEC`, уровень логирования — `LOG_LEVEL`.
